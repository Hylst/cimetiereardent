# Cimetière Ardent : Le Dernier Fanal

**Les morts détestent les étincelles**

Joue en ligne sur : [https://games.hylst.fr/cimetiereardent/](https://games.hylst.fr/cimetiereardent/)

## Description
Un jeu de survie et défense de sanctuaire au coeur d'un cimetière hanté. Choisis ton héros, récolte des reliques anciennes et anéantis les colosses et nécromanciens.

## Controles
| Contrôle | Action |
|---|---|
| ZQSD / Flèches | Déplacement |
| Clic / Espace | Déclenchement d'arcane |
| Tactile | Écran tactile complet avec ciblage auto |

## Developpement
```bash
# Installer les dependances
npm install

# Lancer le serveur local
npm run dev

# Compiler pour la production (build single-file)
npm run build
```
